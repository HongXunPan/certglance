# 隐私与本机数据

本文描述当前开源源码的行为，不替代 macOS 的网络、通知与隐私设置。

## 网络访问

App 和 Widget 只对用户添加的 HTTPS 主机与端口发起证书检查：向端点的 `/` 发出 `HEAD` 请求，从系统 TLS 信任对象读取证书有效期；不跟随 HTTP 跳转读取其他端点的证书。连接目标服务器时，目标及相关网络设施能够获知连接信息。DNS 和证书信任处理还可能涉及 macOS 自身的系统网络行为。

当前源码不包含账户、云同步、分析 SDK 或向项目维护者服务器上传监控列表的逻辑。证书检查失败与证书不受信任会在本机展示，不会被改写成“正常”。

## 本机保存与通知

监控端点、证书快照、提醒设置及通知去重记录保存在当前账户的 `~/Library/Application Support/com.HongXunPan.CertGlance/`。App 可读写项目目录；Widget 只读 `config/` 并读写 `state/`。目录和文件使用受限权限，但同一用户下的其他进程仍可能访问这些文件；这不是 App Group，也不构成对同账户进程的保密边界。

获得系统通知授权后，通知正文可能包含端点名称；锁屏预览是否显示由 macOS 通知设置控制。删除监控端点会从配置和证书快照中移除该端点，并尝试清理不再适用的待发通知；历史通知去重标记可能继续保留端点标识。当前没有云端删除流程，因为没有项目云端账户。

如需清除全部本机项目数据，请先退出 App、移除桌面组件，再由用户自行删除上述专用目录。此操作不可恢复；需要保留的配置应先自行备份。提交 Issue 或 PR 前，请遮盖真实域名、证书、账户路径及通知内容。
