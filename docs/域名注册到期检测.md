# 域名注册到期检测

## 已确认范围与验收状态

本方案已于 2026-11-02 确认。新增域名注册到期监控，与 HTTPS 证书监控独立；不要求域名有网站、DNS 解析成功或开放 443 端口。不新增云服务、付费 API、账户或系统后台 Helper，不修改现有证书 Widget 的身份与展示语义。

## 输入与身份

- 用户单独添加完整注册域名，例如 `example.com`、`example.co.uk`；支持 ASCII 及 Punycode。不自动从现有证书端点创建监控，也不通过截取最后两段猜测根域名。
- 接受域名或 HTTPS URL，URL 只提取主机；非默认端口不用于注册查询。查询响应的域名身份必须与输入完全一致，子域名无独立注册记录时提示用户核对注册域名，不冒用父域名的日期。
- 以规范化注册域名去重，不包含端口。移除注册域名不影响证书端点；移除证书端点也不删除注册监控。

## 查询策略与安全边界

1. 从 IANA 官方 RDAP 引导 JSON 发现服务，不使用第三方聚合代理。只连接 HTTPS 服务，校验证书，限制响应大小、超时和跳转。
2. 读取域名对象顶层日期事件；`registrar expiration` 与 `expiration` 分开保存。存在合法的注册商 RDAP 关联链接时，至多查询一个关联对象，不递归遍历联系人或链接。
3. 无可用 HTTPS RDAP 服务或正常响应缺少日期时，通过 IANA WHOIS 发现该后缀的服务器，再进行一次域名查询；这是明确的协议补充，不是网络异常后的盲目重试。RDAP 404、429、超时、断网或异常响应均不触发 WHOIS 连发。
4. WHOIS 使用 TCP 43，协议不加密、不具备 RDAP HTTPS 的完整性保护。只解析已识别的域名身份字段和日期字段；未注明时区的日期不猜测时区。未标注日期含义的字段显示为“服务报告日期”，不冒充注册商日期。
5. 引导信息在进程内最多缓存一天；同批查询共享一次发现结果及其错误，避免错误引发逐域名重复发现。主动检查可显式重新获取，不在失败后增加即时重试、后台补偿或网页抓取。

可发现服务、可以查询对象、可以取得到期日期是三层不同能力。不声明所有后缀均支持；缺少公开日期时明确显示，手工日期也不冒充自动检测。

## 日期、状态与提醒

- 分别保留注册商到期日、注册局到期日及含义未注明的服务报告日期，优先展示注册商日期。注册局与注册商日期不同时同时展示，并提示以注册商续费信息核对。
- 状态区分待检查、已取得日期、未提供日期、未找到匹配记录、不支持和查询失败。只有拿到日期才安排到期提醒；参考日期的通知明确要求核对续费期限，不声称域名已被注销或停止服务。
- 失败保留最近一次已知日期和成功时间，但当前状态仍为失败。正常响应明确不再提供日期时，不将历史日期冒充新结果。
- 与证书共用用户设置的提醒天数；通知前缀、域名身份和截止时间分开去重。删除域名、续期或修改档位时清理相应待发通知，不能误删证书提醒。
- 不绘制以注册日为分母的有效期圆环；注册时间不能可靠代表当前续期周期的开始。

## 定期查询与生命周期

- 宿主运行期间使用 `NSBackgroundActivityScheduler`，约每 30 分钟评估一次到期队列；证书沿用 12 小时检查间隔，注册域名间隔为 24 小时。启动时也检查到期项；主动检查不受周期门槛限制。
- 调度器归 App 级对象持有，不绑定窗口视图或是否添加 Widget。关闭最后窗口仍保持普通应用运行、保留 Dock 与重开语义；`⌘Q` 退出时取消宿主任务并停止调度，不注册登录项或系统后台服务。
- 域名 Widget 仅显示本地快照、来源、剩余天数、到期日和数据时效，不独立发起 RDAP／WHOIS 查询。已有 TLS Widget 的系统时间线查询行为保持不变。
- 不保证准点执行；睡眠、离线、系统节能与通知权限均会影响结果。退出后不会查询到续期变化，已由系统成功排定的本地通知不依赖 App 持续运行，但可能基于旧日期，需重新打开 App 更新。
- 手动检查与宿主周期检查共享单一进行中任务；不并行叠加同类批次，不因关闭再打开窗口创建重复调度器。

## 数据与模块边界

- 新增独立注册域名模型、协议客户端、响应解析器、仓储扩展、界面模型与 Widget，复用既有文件桥接、原子写入、锁和提醒时间规划。
- 配置写入 `config/registrations.v1.json`，快照写入 `state/registration-snapshots.v1.json`；不修改旧证书 JSON 格式。只保存所需日期、查询状态、来源地址与检查时间，不保存完整 WHOIS／RDAP 联系人响应。
- 新文件损坏时保留原文件，阻止该功能继续写入，允许用户修复后主动重新读取；不得清空数据或影响已有证书配置。

## 验证入口与层级

在 Mac 子仓执行 `bash scripts/check-certglance.sh`：除原有检查外，覆盖根域输入、RDAP 日期语义及身份校验、WHOIS 字段与日期解析、失败保留、移除与旧结果去重、通知隔离和周期门槛。固定测试全部使用假数据及 `example.com`，不依赖实时日期。

真实网络示例：`bash scripts/check-registration.sh --network`。只使用 `example.com`，断言对象身份、来源与可用日期，不将实时日期固定为长期断言。此命令不会写入真实用户配置或安排通知。网络失败应区分 DNS／TLS、TCP 43、防火墙、限流、无服务与无公开日期。固定测试使用 `bash scripts/check-registration.sh`，无需网络。

WHOIS 独立网络检查：`bash scripts/check-registration.sh --whois-network`。同样只查 `example.com`，先向 IANA 发现服务，再验证 TCP 43 和匹配域名的日期；该项失败不代表 RDAP 失败，TCP 43 在某些网络可能不可用。不通过其他代理或重复重试绕过网络限制。

`bash scripts/render-visual-previews.sh` 包含注册列表及小／中号浅深色假数据排版。预览不读取真实配置，也不证明 WidgetKit 的实际边距或运行态通过。

原生无边框按钮在现有 `ImageRenderer` 离屏路径中可能显示占位符，原证书预览也存在同样现象；不为消除离屏占位而改成自绘按钮，实际系统图标、键盘及 VoiceOver 必须在安装后核对。

无签名构建验证 App＋Widget 编译，不替代以下人工验收：未添加 Widget 时周期回调、关闭／重开窗口、退出停止、系统通知投递、真实 Widget 布局与文件共享。不得为验证擅自签名安装、注册服务或发布。

### 后续人工验收

1. 经明确授权签名安装候选；不添加任何 Widget，启动宿主并单独添加授权测试注册域名，确认首次查询与旧 TLS 数据独立。
2. 关闭最后窗口，确认 App 未退出；跨过注册检查周期后，再通过 Dock 打开原窗口，核对各快照的 `checkedAt` 确实更新。重开仅重读快照，不能用手动检查冒充周期查询。
3. 在未添加 Widget 的前提下用 `⌘Q` 退出，退出期间核对快照不再被宿主更新；重启后只检查到期项。原有 TLS Widget 独立时间线不属于此停止结论。
4. 分别验收通知允许、拒绝、设置档位、续期变更与删除域名，检查两类通知不会互删或重复。
5. 添加注册小／中号，检查真实边距、长域名、失败和旧数据提示；退出宿主后明确其仍是旧快照，不宣称重新查询过。
